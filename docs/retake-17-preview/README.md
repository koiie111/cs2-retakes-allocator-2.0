# HTML-макет RETAKE #17

Макет показывает приветствие, список команд, предпочтения снаряжения, очередь, начало раунда и действия администратора. Переключатели за пределами игрового кадра воспроизводят состояния и меняют формат кадра. «Показать выключенные функции» демонстрирует голосование и Zeus. По умолчанию они скрыты, как в конфигурации #17.

## Открытие

Подготовьте изображения штатных агентов, дневного и ночного Mirage из проекта 4ill и извлеките игровые иконки из локального VPK с помощью Source2Viewer CLI. Для подготовки WebP нужен Python с Pillow.

```powershell
./prepare-assets.ps1 -SitePublic C:/path/to/4ill-public -GameArchive C:/path/to/csgo/pak01_dir.vpk -Source2Viewer C:/path/to/Source2Viewer-CLI.exe
```

Откройте `index.html` в браузере. Макет работает с локальными файлами. Галочка «Больше не показывать» хранится в браузере. Кнопка «Сбросить приветствие» возвращает исходное состояние. Игровые действия и состояние плагинов в HTML имитируются.
